Adafruit Blinka Raspberry Pi PWM
================================

CircuitPython-compatible PWM for Raspberry Pi, using configured BCM/RP1 hardware
channels or native software output on other GPIOs. See the usage guide for
system setup, pin mapping, timing limitations, and safe cleanup.
